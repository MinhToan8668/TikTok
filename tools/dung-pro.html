Dựng chuyên sâu dành cho gói Pro

  • Trình dựng kiểu Premiere: Source/Program monitor, timeline nhiều track, trim ripple, roll, slip, slide
  • Lumetri Color: curves, bánh xe màu, HSL, vignette, kèm scopes đo màu thật
  • Keyframe đồ thị Bezier, 93 hiệu ứng, 30 chuyển cảnh, mask
  • Mixer âm thanh, EQ, compressor, đo loudness chuẩn TikTok
  • Trợ lý AI tiếng Việt ra lệnh thẳng cho trình dựng

Bắt đầu một video

  1. Bấm ➕ Thêm footage hoặc kéo video thả vào trình dựng. File ở lại máy bạn, không tải lên đâu.
  2. Chuột phải clip trong Project → New Sequence From Clip, hoặc nhờ trợ lý “tạo sequence dọc 1080×1920”.
  3. Dựng xong vào tab Export ở góc trên trái → H.264 MP4.
  4. Lưu dự án: File → Save tải file .fcproj về máy. Lỡ đóng tab thì mở lại, trình dựng tự khôi phục bản gần nhất.

Chỉnh màu

Chọn workspace Color ở thanh trên. Panel Lumetri Color đi từ trên xuống: Basic Correction (nhiệt độ, phơi sáng, tương phản) → Creative (look) → Curves → Color Wheels → HSL Secondary (chọn riêng màu da) → Vignette. Nhìn Lumetri Scopes bên cạnh: waveform da người thường nằm quanh 60–70.

Âm thanh

Workspace Audio. Đồng hồ bên phải timeline hiện LUFS; TikTok/Reels nên quanh −14 LUFS. Chọn clip → Effect Controls → thêm Dynamics (compressor) cho giọng đều, EQ cắt dưới 80 Hz cho hết ù.

Phụ đề

Menu Sequence → Captions → Add New Caption Track, rồi Ctrl+Alt+C thêm câu tại đầu phát. Có file .srt thì kéo vào là thành caption track. Trợ lý cũng thêm được theo lời bạn.

Trợ lý làm được gì

Xếp clip, cắt, đổi tốc độ, thêm chuyển cảnh, chỉnh màu, thêm phụ đề, đặt marker, chỉnh âm lượng, xem khung hình để tự kiểm. Nói rõ clip nào, giây nào. Không ưng thì bấm ↶ hoặc Ctrl+Z.
